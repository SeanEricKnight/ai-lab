# AI Lab

> **Build. Verify. Learn. Repeat.**

AI Lab is an engineering laboratory for local AI, software, architecture, experiments, and learning.

The lab has two equal outputs:

1. Reliable software.
2. Better engineering judgment.

The repository preserves not only what was built, but why it was built, how decisions were made, and what was learned along the way.

## Current environment

- **PowerSpec G913 workstation** — primary local LLM development and inference machine.
- **JARVIS (Unraid)** — storage, Linux testing, Docker work, infrastructure experiments, and supporting lab services.

## Working loop

**Idea → Hypothesis → Experiment → Build → Verify → Knowledge Check → Reflection → Lab Report → Commit**
